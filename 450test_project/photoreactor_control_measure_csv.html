USB 연결 안 됨
연결 전 주의 · 24V SMPS는 OFF로 유지한 채 USB 및 PWM 핀 매핑을 검증하세요. 화면의 OFF는 24V 전원을 차단하지 않습니다. Teensy가 재부팅되거나 PWM 입력이 분리되면 AL8862의 LED가 예상치 않게 켜질 수 있습니다.

2. PWM 제어

전송 명령: SET 1 50

PWM 채널 1~24는 현재 펌웨어의 임시 GPIO 매핑 기준입니다. 실제 LED PCB 채널과의 일치는 별도로 검증해야 합니다.

측정 횟수는 자유롭게 결정할 수 있습니다. 각 회차의 센서 0·1·2 결과가 누적됩니다. 연결 해제 또는 새로고침 후에도 이 브라우저의 임시 저장소에 기록을 유지하도록 구성했습니다.
